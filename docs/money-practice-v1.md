# 理财航线 1.1.0：交易练习

实现范围：今日任务、观察记录、计划/委托/成交、单笔复盘/阶段选择、能力证据/问题/AI接手，以及二级设置与独立备份。仅做记录与教学流程，不连接券商，不发证券订单，不接行情API，不识别截图，不监控价格，不承诺后台通知。

## 与原预算的边界

- 原 `money-route.v1`、格式1预算备份及金额计算不改。练习使用 `money-route.practice.v1`。换设备前两处分别导出，不能把旧预算备份当作包含练习。
- 原App没有真实持仓/现金总账，本版不伪造资产余额，不导入用户长期持仓或配置草案。模拟1000元与平台大额虚拟账户分开，不能并入真实资产。
- 实盘仅本人完成准备、主动选择后允许记录。初始真实现金为0；确认一次已发生的1000元内部划转才有训练现金。登记归属名称与关联标识，不存账号。原资产总账需由本人相应减少现金，不重复增加总资产。此登记不转账、不扣原消费预算。

## 数据与计算

完整JSON：`app: money-route-practice`，`format: 1`，`currency: CNY`，`moneyUnit: cents`，`priceUnit: milliCny`，`events`。事件为追加记录；类型包括setup、settings、observation、plan、order、order_status、fill、fill_correction、review、evidence、question、task、pause、decision、live、funding。ID、时区时间、字段、关联及金额均校验，未知费用/报价用null。

- 元费用转整数分，ETF价格转0.001元整数；先乘数量再四舍五入到分。先记录委托只冻结资金，成交才改变现金和持仓。
- 部分成交逐条录入，费用为本条分摊额。未知费用可按计划比例估算，但永远标估算；不会默认为0。实际0元需填写0并选择已核实。
- 净损益=卖出净收入−买入总支出；现金已扣费用不再扣第二次。权益包含已冻结现金一次。持仓清算估计另扣计划预计卖费；缺报价/费用则未知。
- 剩余成本按买入总成本和累计卖出比例分摊，保存每次实际成交原值。完整闭环结果按全部收支计算。报价来源、时间、延迟状态跟随展示和导出。
- 计划改版须有原因，保留旧版本。已有委托的计划快照锁定；设置只影响新计划。成交纠错追加事件并保留原值；纠错后的旧复盘提示重新核对。
- 外部委托与成交标识分别防重；备份恢复整体替换练习事件，不合并重算同一成交。先保存导入前副本，失败不改当前数据。

## 约束与真实进度

初始化模拟、准备中、0笔交易、0项任务完成、没有测量收益、提醒未启用。只读解释不会产生掌握证据；完成任务也不代替准备、观察或成交。

默认1000元、100份、最多1笔持仓、不补仓/加杠杆、首阶段最多2回合、实际成交日为持有第1天、下方3%/上方4%/最长5交易日、保守清算损失50元暂停。均为未验证的演练参数，不保证成交或损失上限。暂停会保留，价格反弹不自动恢复；仍可登记卖出、撤单、补记此前成交、纠错和复盘。

买前两个真实观察日；上一笔退出后先复盘；现金含费不足时可保存不可执行草稿但不能登记新的买入委托。手工模拟明确未经撮合验证；实盘禁止手工假设委托。未知日线路径不能冒充真实成交。

实盘检查要求10个实际观察日、闭环复盘、全部独立能力证据、费用核实，随后本人勾选并主动选择。模拟盈利或日历到期都不自动切换。证据由本人录入，并非AI已经核实其合法资格或预测盈利能力。
