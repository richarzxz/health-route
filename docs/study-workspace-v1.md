# 学习航线 1.1.0：第一版学习工作台

目标：每次打开，知道当前学什么、已做到什么、还卡在哪里、下一步只做什么，并能把这些信息交给 GPT 继续教学。

## 第一版的取舍

- 同时只维护一个当前学习项目和一个下一步任务；长期安排用可编辑的阶段列表表达。
- 阶段位置、掌握自评、任务完成和掌握证据分别记录，不折算成百分比。
- 保存一次完成时，把当时的任务和产出一起留存；没有下一课内容时由用户与 GPT 决定，不自动编课程。
- AI 老师偏好写入接手文档；复制或导出后由用户交给 GPT。没有内置模型调用。
- 不加入课程播放器、账户、云同步、消息推送、打卡排名和到期限制。

## 数据结构

保留 `study-route.v1` 的旧字段 `units`、`log`、`books`、`goals` 和 `draft`，增加可选的 `workspace`。没有工作台的旧记录照常读取。

| workspace 字段 | 内容 | 约束 |
|---|---|---|
| version | 工作台结构版本，当前为 1 | 不支持的结构拒绝导入 |
| project | id、名称、目标、当前阶段、概念、小技能、自评、自评理由、薄弱点 | 一个当前项目；自评不等于证据 |
| route | id、阶段名称、完成标准、planned/current/done | 最多一个当前阶段；阶段完成是用户判断 |
| task | id、标题、想知道什么、起步例子、完成标准、todo/doing/done、work | 唯一的下一步任务 |
| task.work | 具体问题、意图、例子、A/B 预判、观察证据、猜测、困难、下一步想法 | 未完成输入保存到本机 |
| sessions | 日期、completed/paused、摘要、当时的阶段/概念/技能、完整任务快照 | 调整任务时保留已有产出 |
| evidence | 日期、taskId 或 null、标题、具体产出、完成方式、反馈来源、核对结论、反馈依据 | 完成方式为提示/独立/迁移；新任务产出默认尚未核对 |
| questions | 日期、问题、解答/依据、parked/resolved | 无解答不标为已解决；不改变当前任务 |
| teacher | 解释方式、节奏、练习方式、避免事项 | 作为交给 GPT 的教学偏好 |

ID 使用唯一的字母、数字、下划线和连字符。数据进入 HTML 时转义；备份检查 ID、日期、枚举、任务快照及证据关联。未知或损坏的本机工作台阻止写入，避免覆盖原始内容。

## 页面结构与最小功能

八个按钮对应八个视图，手机上为两行导航；不需要层层进入菜单。

| 页面 | 第一版显示/操作 |
|---|---|
| 当前状态 | 项目、阶段、概念、小技能、自评及理由、最近产出、薄弱点、下一步入口 |
| 下一步 | 一个任务、完成标准、三个核心输入；折叠的 A/B、证据与猜测；保存进度或完成 |
| 学习路线 | 阶段列表、当前阶段切换、完成标准；编辑项目与自评；设置新的下一步 |
| 学习记录 | 新项目的完成记录与任务快照；折叠保留原有练习、用时图表、概念库、书单 |
| 掌握证据 | 具体产出、完成方式、来源和核对结论；补充新场景应用或实际反馈 |
| 问题停车场 | 添加暂不展开的问题；填写解答依据后标记解决；可以重新停放 |
| 老师偏好 | 编辑解释方式、教学节奏、练习方式、避免事项 |
| GPT 接手 | 自动生成当前文档；复制或导出 Markdown；剪贴板不可用时支持手动复制 |

所有页面下方均有“备份与导入学习方案”。旧练习和新工作台明确分别记录；旧练习次数不会自动成为新项目的掌握证据。

## 完成与掌握

任务完成至少包含具体问题、想知道什么和起步例子。记录完成只表示保留了学习产出，默认证据结论为“尚未核对”。

提供 AI/他人反馈，或把结论标为符合标准/仍需练习时，必须写明实际反馈或核对依据。即使新场景应用记录通过，也不会自动改变项目自评。

## 备份与接手

- 新导出学习备份使用 `format: 2`，包含工作台和全部旧数据、旧练习草稿；继续接受旧 `format: 1`。
- 导入旧备份不修改现有工作台。新备份的工作台整体替换当前工作台，在确认区域明确说明范围；旧练习仍按原规则合并。
- 导入前保存完整本机副本，副本写不进去则停止；它不替代导出到外部的独立备份。
- 接手 Markdown 包含当前任务的全部已填内容、薄弱点、最近 5 条项目记录、最近 5 份证据、路线、前 10 条未解决问题、旧练习当前轮次/草稿和老师偏好。它是上下文摘要，不是完整数据备份。
- 源码仓库公开；真实初始学习状态和记录通过本机导入，不放入公开源码。

## 验证边界

逻辑检查覆盖旧数据迁移、任务重开、失败保存重试、完成快照、证据与自评分离、停车场、老师偏好、接手内容、输入转义、格式 1/2 备份以及离线回退。真实 iPhone 安装、系统分享和存储行为仍需实机确认。
